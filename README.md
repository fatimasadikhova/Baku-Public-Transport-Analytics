# Baku Public Transport — Passenger Trips & Payment Methods | 2026

An interactive Power BI dashboard designed to analyze passenger trips, passenger flow across public transport modes, and payment methods in Baku.

## Dashboard

![Report Preview](https://raw.githubusercontent.com/fatimasadikhova/Baku-Public-Transport-Analytics/main/report%20image.png)

## Key Metrics

The dashboard covers the following key areas:

- Total passenger trips
- Comparison of Metro and BakuBus trips
- Share of digital payments
- Breakdown of Smart Card, NFC and QR payments
- Top 5 busiest metro stations
- Monthly passenger flow trends
- Passenger density by day of the week
- Metro lines and stations visualization

## Tools & Technologies

- **Power BI**
- **DAX**
- **Deneb**
- **HTML Content**
- **Power Query**
- **SVG / HTML-based custom visuals**

## Visualization Approach

The dashboard was designed with a focus on creating a modern and analytical user experience rather than relying only on standard Power BI visuals.

Key visualization techniques include:

- **Deneb** for custom visualizations and the metro network map.
- **HTML Content** for custom KPI cards and UI elements.
- A consistent color system to visually distinguish Metro and BakuBus data.
- Custom layouts and visual elements to make the dashboard more intuitive and engaging.
- A storytelling-focused approach that goes beyond displaying numbers and highlights passenger flow patterns.

## Key Insights

For the selected period in 2026:

- **273M** total passenger trips
- **137M** Metro trips
- **136M** BakuBus trips
- **49.5%** of payments were made through digital methods
- **Koroglu** was the busiest station among the Top 5 stations
- Passenger flow is generally higher on weekdays and decreases significantly during weekends.
- Passenger trips are almost equally distributed between Metro and BakuBus.

## Project Goal

The main goal of this project is to transform public transport data into an interactive analytical environment that makes passenger behavior, transport usage and payment patterns easier to understand.

The dashboard aims to support **data-driven decision-making** by combining clear KPI reporting with interactive and custom data visualizations.
